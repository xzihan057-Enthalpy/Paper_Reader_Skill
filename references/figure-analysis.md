# Figure、统计与证据链

## 先确认真正看到了什么

实际查看目标 Figure 的图像或渲染页面，再与图注、相关正文及 Methods 对照。记录版本、页码和 panel；扫描件要检查轴、上下标、单位、色标与字体是否可辨。若只有 caption，可以解释其文字和所需知识，但必须写明图像未提供，不能补出形状、离群点或视觉趋势。

对所有主图与关键补充图建立用途索引，区分已查看、只读图注、未读取。正文已经提到的图不能自动计为已检查。图像观察没有原始数据的精度，不从像素猜精确 n、p-value 或参数。

## 七个问题与 panel 记录

每张重要 Figure 回答：问什么，如何设计，每个 panel 显示什么，数据说明什么，支持哪个结论，在完整论证链中有什么作用，以及不能证明什么。

| 字段 | 分析内容 |
| --- | --- |
| 问题与设计 | 假设、系统、干预、对照、时间点、样本单位 |
| 图形编码 | 轴和单位、比例或对数变换、每个点/线/颜色/误差带代表什么 |
| 观察 | 实际可见模式，注明原文报告值与图中估读的区别 |
| 证据 | 对照和统计如何使观察支持 claim，效应大小及不确定性 |
| 解释与结论 | 作者的解释、必要推理、竞争解释、适用范围 |
| 论证位置 | 承接哪张图、回答了什么遗留问题、支持后续哪一步 |

用 `Figure → Evidence → Claim` 追踪，保持 Observation / Evidence / Interpretation / Conclusion 的区分。多个 panel 可能并列、递进或跨尺度，但排在同一张图里不构成因果证明。

## 定量图应教会读者什么

先定义横轴、纵轴、样本单位与可视化选择，再解释论文真正使用的统计量。没有给出某个指标时，可以讲其概念，必须说明它未被本文报告，不自行配值。

对于散点图，解释 Pearson 相关系数是线性共同变化经标准差归一化后的量；如果有助理解，可写：

\[
r=\frac{\sum_i(x_i-\bar{x})(y_i-\bar{y})}
{\sqrt{\sum_i(x_i-\bar{x})^2\sum_i(y_i-\bar{y})^2}}.
\]

\(i\) 是配对观测的索引，\(x_i,y_i\) 是该观测的两个变量值，\(\bar{x},\bar{y}\) 是样本均值；分母要求两变量均有非零变异。解释正负号、线性强弱和对离群点的敏感性。Spearman 相关基于秩，关注单调关系，不能与 Pearson 混称。相关系数不是回归斜率，相关为零也不排除非线性关系。

p-value 是在指定零假设及检验模型成立时，获得至少与当前观察同样极端的检验统计量的概率；不是“零假设为真的概率”，也不是“结果由偶然造成的概率”。说明零假设、检验统计量、单/双侧、配对结构与多重比较。未报告这些内容时记录缺项，不靠图注星号推断。

频率学 confidence interval 的覆盖率描述重复抽样构造区间的长期表现，不能一般地说已观察到的区间有 95% 概率包含固定真值。Bayesian credible interval 是给定数据和模型的后验概率区间。图中的阴影也可能是 SD、SEM、bootstrap 区间或预测区间，必须查图注。

effect size 解释差异或关联的幅度以及单位、生物学尺度和不确定性。p 小不保证效应重要，p 不显著不证明无效应或等效。样本量与统计功效的不足要有依据，不能仅凭“小样本”宣布结果为假。

检查 confounder、反向因果、选择偏差、heteroscedasticity、outlier、非线性、群组混合与重复测量。异方差是误差方差随条件变化，影响某些标准误和检验假设；图像只能提供线索，缺原始数据不能宣称已做检验。将作者统计结论与实际分布对照，疑似不一致说明依据和分辨率限制。

## 模型拟合图

完整解释：

```text
Data → Model → Parameter estimation → Fitted curve → Residuals → Prediction
```

说清拟合用的是哪些点、什么目标函数、哪些参数，曲线是拟合均值、模拟轨迹还是新条件预测。残差如 \(e_i=y_i-\hat y_i\) 是数据与预测之差；关注系统偏离、方差结构和时间相关。作者未画残差且没有原始数据时，写“未提供，无法据此判断”，可以建议分析但不能假称已经完成。

区分训练拟合与独立验证，参数扫描与经验估计，置信带与预测带。需要数学教学时加载 [quantitative-models.md](quantitative-models.md)。高拟合优度不能排除另一种机制或模型同样拟合。

## 按图类型检查

| 类型 | 具体检查 |
| --- | --- |
| 比较、柱状、箱线、小提琴图 | 点是个体还是技术重复，箱体/须的定义，分布、配对、效应量、误差线和多重比较 |
| 显微、免疫荧光、活细胞图像 | 比例尺、染色/阴性对照、采集与显示范围、代表图与群体定量；可疑伪影不能直接称造假 |
| 干预、knockout、rescue、药理实验 | 特异性、脱靶、表达量、时间顺序、必要性与充分性、是否排除间接效应 |
| 时间序列、电生理、行为 | 时间轴、基线、滤波、对齐、试次与个体数量、细胞/受试者层级、记录条件与盲法 |
| Heatmap、volcano、组学 | 原始单位与标准化、颜色范围、fold change、p 与 FDR、独立样本、批次和筛选阈值 |
| PCA、t-SNE、UMAP、聚类 | 降维目的、预处理、轴的意义、参数敏感性；低维距离或分群不能自动代表机制或真实细胞类型 |
| 预测验证、模型比较 | 预测在何时产生，验证数据独立性、基线、外推范围、比较是否公平、不符合预测的部分 |
| 综合、多尺度图 | 各层证据是否来自同一系统，层间推理需要哪些额外假设，示意箭头与因果证据分开 |

GO 等富集图要解释背景集合与多重检验；显著富集不代表通路活性已被直接测得。生物学重复、技术重复、事件数和细胞数分别记录，避免伪重复。

完成时将每张关键图的 claim 链接回核心结论表，明确支持范围、尚未排除的解释以及可补的对照。
