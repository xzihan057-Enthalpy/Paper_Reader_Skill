# 实验方法：从原理到本文

对决定核心结论的方法解释完整测量链：

```text
原理 → 测量对象 → 信号如何产生 → 原始数据 → 处理 → 指标变量 → 科学问题
```

先说明用户需要理解的方法原理，再定位论文实际使用的版本和参数。通用原理标记为背景知识，论文实现附 Methods/补充材料位置。常见操作不能自动视为本文做过。

## 测量与推断

分别写清真实生物变量、仪器直接测得的量、经过处理产生的指标，以及指标为何可作为该生物变量的代理。用观测模型的思想连接它们，但不强制给没有模型的论文新增公式。

说明采样时间/空间尺度、仪器响应、噪声、背景、检测限、漂移、饱和、选择偏差和处理误差中与本文有关的部分。记录校准、对照、随机化、盲法和重复的已报告信息。没有报告不等于没有实施，也不应写成已实施。

解释 normalization 的分子、分母、单位和比较基准。比值变化可能来自分子也可能来自分母；经标准化的量未必保留绝对生物量。阈值、筛选、分割、去噪、对齐和平均都可能改变后续统计单位与误差结构。

## 按实际方法展开

| 方法 | 从原理到本文必须说明的连接 |
| --- | --- |
| fluorescence imaging | 荧光团/标记来源，光子或像素强度，背景扣除、分割、漂白与归一化，信号与丰度/定位的关系；更亮不自动等于更多蛋白 |
| calcium imaging | 指示剂如何响应钙，荧光与钙浓度、放电的间接关系，时间响应；若使用 ΔF/F₀，定义 F₀ 及其估计方式；去卷积不是直接测到 spike |
| patch clamp / electrophysiology | 电压钳或电流钳测量什么，电极与电路原理，记录条件、串联电阻/漂移，事件检测与细胞统计层级 |
| RNA-seq / single-cell RNA-seq | RNA 到 reads/UMI/counts 的链条，捕获、比对/定量、QC、归一化、批次；单细胞数不能替代独立供体数，counts 不直接等于蛋白量 |
| fMRI | BOLD 与血氧和血流的联系、间接神经指标、血流动力学延迟，运动/生理混杂、预处理与模型设定 |
| optogenetics | 光敏蛋白、光照如何干预细胞，表达与光照对照、加热/脱靶/时序，网络间接效应；刺激有效不证明被刺激细胞是唯一路径 |
| behavioral tracking | 传感器或图像到位置/姿态、标定、遮挡与插值、速度/策略指标、试次与个体、任务条件对行为的约束 |
| image analysis / machine learning | 输入、标签或训练目标、预处理、训练/验证拆分、指标、域偏移；算法输出不自动等于生物学真实分类 |

表格只用于选取方向；最终解释使用本文实际仪器、变量和流程，不能只重复方法名称。

## 设计为何能回答问题

将方法连接回具体假设：干预改变哪个变量，其他变量如何控制，哪种测量结果能支持或挑战假设。阴性、阳性、载体、sham、rescue 等对照各排除什么？干预是否存在非特异效应？时序与测量速度能否区分竞争机制？

优点和局限以这篇论文的问题为准。说“分辨率高”时说明哪一种分辨率、为什么影响判断；说“存在系统误差”时指出误差通过哪个环节影响哪个结论。缺细节时标记无法确认，给出需要补充的信息。
