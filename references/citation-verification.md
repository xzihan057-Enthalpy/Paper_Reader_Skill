# 文献核验与来源记录

## 核验什么

书目是否匹配、正文是否支持一个结论、是否真的看过某张图是三个不同问题。DOI 可以解析，不代表它对应目标论文；元数据匹配，不代表数据库核实了实验结果。论文 References 是检索线索，不能因“作者引用过”就把它标成已独立核验。

从获取材料时持续记录来源，不在交付前靠记忆补出处。按 [citation-record.md](../assets/templates/citation-record.md) 建立记录。

## 来源优先级及用途

1. 论文 PDF、正式全文与 supplementary materials：确定所读版本、实验、公式、图表、参数及作者结论。
2. PubMed：核对生物医学书目、PMID、DOI 和记录中的发表日期。
3. Crossref：核对 DOI 注册元数据；数据和软件 DOI 可补查 DataCite。
4. OpenAlex：交叉核对书目、开放获取位置、引用关系。聚合记录仍可能有误。
5. arXiv：核验预印本标识、版本号、日期及明确关联的发表版本；其他预印本使用其官方平台。
6. 出版商官网：核对正式版本、勘误、撤稿或版本关联，以及可访问的全文和补充材料。
7. 其他可靠数据库、教材及机构来源：按所需字段和实际覆盖使用。

这是检索起点，不要求每篇论文逐站遍历。字段核验使用最适合该字段的一手来源。搜索引擎摘要、snippet、Google Scholar 结果和模型记忆只提供线索，不确认 DOI、PMID、数字或细节。`doi.org` 是 DOI 解析入口，并不是 Crossref 元数据查询本身。

## 书目核验步骤

从论文实际页面提取标题、作者、期刊/会议、年份、版本和可见标识符；PDF 元数据可能陈旧，要与页面核对。只写确实出现的通讯作者、单位、卷期页码。

已有 DOI 时访问权威记录或解析页面，比较完整标题、第一作者、其余作者与出版信息。无 DOI 时按标题和作者查找候选，再做身份匹配。年份差异可能来自预印本、online-first 和正式卷期，分别记录，不能只因年份不同排除，也不能只因标题相似确认。

仅在 PubMed 中找到并核对记录后确认 PMID。不预设生物论文都有 PMID，也不预设所有预印本均没有 PMID。arXiv 记录保留版本号；对读到的预印本和正式版分别建项，不用新版方程或 Figure 编号替换旧版却不说明。

对引用的外部文献至少核对标题、第一作者、年份和出处。若只查到书目信息，允许推荐阅读，但不能声称已经读过全文或用它支持尚未查看的具体结论。教材记实际版本和章节，不猜页码；软件与数据库记版本、链接、访问日期及实际提供的标识符。

## 逐项状态

| 状态 | 含义 |
| --- | --- |
| 已核验 | 目标字段或陈述已与实际打开的相应权威记录/原文位置匹配 |
| 仅原文提取，外部未核验 | 如从 PDF 首页读到了 DOI，但尚未访问外部记录确认对应关系 |
| 部分核验 | 部分字段匹配，其余明确列为未核验 |
| 未核验 | 缺来源、未打开来源、网络失败或证据不足 |
| 来源冲突 | 不同版本或记录不一致，记录差异与处理依据 |
| 不适用 / 当前未找到 | 明确不适用，或仅在已查范围没有找到；后者不等于不存在 |

状态按字段设置，不因为标题匹配就整条记录全部通过。记录真实访问日期、URL 或文件路径、页码/章节、查到了什么。离线时可以忠实提取并解释提供的论文，保留外部未核验状态，不虚构查询经过。

## 数字与结论的追溯

样本量、p-value、效应量、置信区间、参数值及误差都记录对应 Figure/panel、表格、公式或正文位置。区分 n 的单位、组别、时间点、分析子集和技术/生物学重复；没有这些信息就不能自行配上数值。

图上估读要注明“图中估读”及分辨率限制，不报告虚假精度。自己的计算列输入来源、公式、假设与方法，标记为补充计算。没有原始数据时不能声称复算了显著性、残差或相关系数。

引用次数只有任务确实需要时才记录，附数据库、统计范围和日期；PubMed/PMC 的链接列表不能当作完整通用被引计数。未经读证不得编造数量。

论文原文、外部资料、教学补充、分析判断按主技能的四类标签分开。外部标准知识不自动证明本文实验采用了同样设定；作者没有解释的动机不补成原话。

## 冲突与 correction log

发现错误时保存日期、旧说法、修正、核验依据与受影响的文档位置。没有发生修正则写“本次未发生修正”，不用虚构示例填表。

原文自身疑似印刷错误时，翻译保留并在译者注说明；分析可给出有依据的修正建议，标记为自己的判断。不能静默改公式。发现正式勘误或撤稿信息时核对官方记录，说明它对解读的具体影响。

核验失败不反复重试无关站点。尝试合理的权威替代来源后，记录缺口并继续有材料支持的工作；缺失事实不能靠流畅文风补齐。
