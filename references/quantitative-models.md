# 定量模型的教学式推导

本文用于重要数学模型、统计模型、计算模型和机制模型。按论文需要选读，不把这里的示例或方法清单塞进所有解读。

## 从现象走到数学对象

先明确实验观察留下的问题：是看不到内部状态、无法区分机制、需要预测扰动响应，还是需要从噪声中估计效应？随后说明模型描述的对象，以及仅凭定性叙述为何不足。比较一个更简单的形式，说明论文增加复杂度解决了什么；作者未交代选型原因时，把理由标成分析判断。

选择模型的理由必须落在数学结构与实际问题的对应上：连续时间变化可用 ODE 描述，空间输运可能需要 PDE，计数或二元响应可使用合适的 GLM，隐藏状态与噪声观测可用 state-space model，参数不确定性可在 Bayesian model 中表达。不能由研究领域反推作者使用了某种模型。

模型教学遵循：

```text
直觉 → 背景知识 → 数学定义 → 建模假设 → 方程建立 → 推导 → 参数解释 → 数据连接 → 生物学解释
前置知识 → 局部概念 → 简单例子 → 论文公式 → 数学推导 → 数据 → 生物学解释
```

## 建模对象与符号表

定义输入、状态、潜变量、观测、输出、参数、噪声和初始/边界条件。符号第一次出现就解释；符号表再统一记录其单位、维度、取值范围、是否可测，以及数值是作者设定、数据拟合、外部测量还是未报告。

区分变量和参数：随时间变化的状态与对一次拟合固定的速率不是同一对象；参数也可能跨实验条件变化。区分噪声来源：过程噪声描述系统本身的随机性，测量噪声描述观测误差。

先讲符号所指的对象，再讲公式。例如时间导数是单位时间内状态的局部变化率，状态空间是状态向量所有允许取值的集合。解释速率与时间尺度的互逆关系时，检查单位并说明适用模型。

## 推导规范

为关键模型建立一个从假设到可观测预测的连续推导。每步包含当前式子、使用的定义/数学事实/假设、必要中间式，以及对结果的解释。不要用“由公式可得”跨过关键步骤。

论文有推导时忠实重建并附公式号/补充页码。补足省略步骤、使用自选简单例子或重推标准结论时，标记 `【补充推导，不是论文原文】`，说明与原公式的对应关系。给外部推导时附实际查阅来源。无法确认一个中间步骤，就指出断点，不能拼成看似完整的证明。

逐项核查：独立同分布、条件独立、Gaussian assumption、线性化、小量近似、Taylor expansion、稳态、时间尺度分离、连续极限、边界条件和正规化。写明近似适用条件、被舍弃的项，以及可能改变的生物学含义。

区分等式、近似、比例关系、期望与一次实现。检查标量/向量/矩阵维度、量纲、符号正负、极限情况与初值。数值求解给算法思路、步长或收敛要求的已知部分；不能假装存在解析解。

## 示例一：从守恒直觉推到 ODE 预测

【补充推导，不是论文原文】以下为教学示例，不含任何目标论文数据。仅在相关模型教学需要时使用。

令 \(x(t)\) 为某物质的浓度，生成速率 \(s\) 为常数，单位为浓度/时间；每单位时间按固定比例 \(k\) 清除，\(k\) 的单位为时间的倒数。假设空间充分混合、清除为一阶过程、体积恒定。

在小时间段 \(\Delta t\) 内，“存量变化 = 生成 - 清除”给出：

\[
x(t+\Delta t)-x(t)=(s-kx(t))\Delta t+o(\Delta t).
\]

这里 \(o(\Delta t)\) 表示除以 \(\Delta t\) 后趋于零的余项。两边除以 \(\Delta t\)，令 \(\Delta t\to0\)，由导数定义得到：

\[
\frac{dx}{dt}=s-kx.
\]

设 \(k>0\)。平衡态满足变化率为零，因此 \(x^*=s/k\)。定义偏离平衡的变量 \(z=x-x^*\)；因为 \(x^*\) 是常数，\(dz/dt=dx/dt\)，代入得：

\[
\frac{dz}{dt}=s-k(z+s/k)=-kz.
\]

乘以积分因子 \(e^{kt}\)，由乘积求导法则：

\[
\frac{d}{dt}(e^{kt}z)=e^{kt}\left(\frac{dz}{dt}+kz\right)=0.
\]

所以 \(e^{kt}z(t)=z(0)\)，得到：

\[
x(t)=\frac{s}{k}+\left(x(0)-\frac{s}{k}\right)e^{-kt}.
\]

时间尺度 \(\tau=1/k\) 表示偏离平衡的幅度下降到初值的 \(1/e\) 所需时间。\(s/k\) 具有浓度单位，\(kt\) 无量纲，量纲一致。若 \(k=0\)，不能使用含 \(1/k\) 的表达式，应回到方程得到 \(x(t)=x(0)+st\)。

浓度不一定是直接测到的荧光。一个可能的教学观测模型是 \(y_i=a x(t_i)+b+\epsilon_i\)，其中 \(a\) 为信号尺度、\(b\) 为背景、\(\epsilon_i\) 为测量误差；不能未经证据说论文实际采用了它。解释如何把实际仪器信号映射到模型状态，再比较预测与测量。

若只有平衡浓度且可直接测到 \(x\)，通常只能识别比值 \(s/k\)，不能分别确定 \(s\) 和 \(k\)。时间轨迹可能提供额外约束，未知尺度和初值仍会影响可辨识性。这个例子说明“拟合成功”与“每个机制参数都被确定”不同。

## 示例二：从条件概率推到贝叶斯更新

【补充推导，不是论文原文】以下离散假设例子只用于说明 Bayes' theorem，不是目标论文的推断结果。

令 \(H\) 为候选假设，\(D\) 为观察数据，\(P(H)\) 为看到当前数据前的先验权重。\(P(D\mid H)\) 表示假设成立时数据的概率，作为 \(H\) 的函数称为似然；它不是“已知数据后假设的概率”。后验 \(P(H\mid D)\) 才是利用数据更新后的权重。

由条件概率定义：

\[
P(H\mid D)=\frac{P(H,D)}{P(D)},\qquad
P(D\mid H)=\frac{P(H,D)}{P(H)}.
\]

代入联合概率 \(P(H,D)=P(D\mid H)P(H)\)。当 \(P(D)>0\) 时：

\[
P(H\mid D)=\frac{P(D\mid H)P(H)}{P(D)}.
\]

对一组互斥且穷尽的假设 \(H_j\)，全概率公式给出：

\[
P(D)=\sum_j P(D\mid H_j)P(H_j).
\]

固定同一份数据后，分母对候选假设相同，因而写成 \(P(H\mid D)\propto P(D\mid H)P(H)\)。比例号省略的是归一化常数，不能直接将未归一化权重称为概率。

如果推断对象是连续参数 \(\theta\)，改用概率密度 \(p\)，分母为 \(\int p(D\mid\theta)p(\theta)d\theta\)。密度值不是单点概率。必须解释论文估计的是假设、参数还是潜在轨迹，prior 从何而来，likelihood 如何由实验测量产生，posterior 怎样生成与实验比较的预测。

独立观测时才可将联合似然写成逐项乘积；取对数将乘积变成求和，可解释 maximum likelihood 的目标。MAP 是后验密度的最大点，MLE 是似然的最大点，两者均不等于完整后验分布。

## 按实际模型补齐知识

| 论文涉及的内容 | 应补的基础与本文特有检查 |
| --- | --- |
| ODE、PDE、dynamical systems、neural dynamics | 状态、导数、守恒或反应规律、初边值、平衡与稳定性；用到时解释 Jacobian 与特征值的局部意义 |
| state-space、latent-state、Kalman filter | 状态转移与观测方程、不可见状态、过程/观测噪声；从预测和测量按不确定性加权讲更新，标准滤波的线性高斯条件，非线性扩展的近似 |
| Bayesian inference、MCMC、variational inference | 密度、条件概率、先验/似然/后验、积分为何难；采样与优化各近似什么，收敛、有效样本量或变分偏差 |
| regression、GLM、maximum likelihood | 响应变量、设计矩阵、线性预测量、link 与分布；损失为何对应似然，残差和误差模型不是同一概念 |
| neural network、RNN、dimensionality reduction | 矩阵乘法、隐状态/embedding、损失、梯度、优化；训练目标与生物机制分开，降维距离与原空间差异 |
| Markov process、stochastic process | 随机变量、转移概率、条件依赖；Markov 假设不等于各时刻互相独立 |
| optimal control、motor control、reinforcement learning | 状态、动作、动力学、代价/奖励、策略；优化什么、可用信息是什么、辨识与控制的区别 |
| system identification、biomechanics、behavioral modeling | 激励输入、物理约束、测量映射、参数可辨识；任务条件与系统本身是否混淆 |
| predictive coding、Bayesian brain、information theory | 先限定论文的具体公式与操作定义；理论类比、算法实现与真实神经机制的证据分开 |
| Fourier transform、频域分析 | 基函数、振幅/相位、采样率与频率分辨率；有限窗口、混叠与预处理怎样影响解释 |

不需要时跳过整行；需要时用简单例子过渡到论文实际符号，不能只附一句词典定义。

## 参数估计、数据与验证

明确哪些数据用于拟合、选择超参数、验证或最终测试。独立性以生物学单位为准：同一受试者、同一轨迹或高度相关时间片拆分到两侧可能泄漏。辨别拟合插值、留出预测、新条件外推与实验前的预测。

写出论文实际目标函数、似然或后验；解释每项、约束、正则化和优化/求解方法。若只给软件名称，不凭经验补出默认参数。报告实际公开的参数值、单位、不确定性与来源；没有原始数据就不声称完成了复现。

将状态预测经过观测模型转成与实验同单位的输出，再比较拟合曲线和数据。解释残差、系统偏差、噪声、可辨识性、灵敏度、模型比较、消融以及对假设的依赖。R² 高不能证明机制唯一，参数置信区间也不能消除模型设定错误。

若建议替代模型，说明它改变了哪条假设、能解释哪些现有数据、什么新实验可以区分。最后回到生物学：哪些结论来自数据，哪些来自模型假设，哪些预测已验证，哪些仍待检验。
