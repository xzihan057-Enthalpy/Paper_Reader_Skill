# 科研阅读与前置知识

## 从读者的起点组织内容

默认读者掌握高等数学和线性代数，尚未系统学习高级统计、动力系统或机器学习。先通读以找出依赖，再在交付文档的基本信息之后安排“阅读本文前需要知道什么”。写作顺序不必等于阅读顺序。

前置知识分为研究领域背景、必要生物学概念、实验方法、数学/统计/计算知识和关键术语。每个必要概念给出中文名、英文、基本定义、直觉、本文为什么需要它、在本文具体指什么。术语可以融入解释，避免堆一张无人使用的大词表。

只教对后文有用的知识。例如理解膜电位与放电率的区别后，才能判断实验到底测到电压还是发放事件；理解潜在状态后，才能讨论行为观测是否足以估计内部状态。解释 state-space model 时不要直接列状态转移方程，先说明什么是不可直接观察但影响测量的状态。

复杂内容采用“前置知识 → 局部概念 → 简单例子 → 论文公式或实验 → 推导或测量 → 数据 → 生物学解释”。一个小例子只承担一个教学目标，并明确它不是论文实验或数据。前置层完成入门，局部教学完成本文特有细节；以链接连接两者。

## 科学问题与知识空白

分别回答：研究对象是什么，领域此前知道什么，还不知道什么，这篇论文检验其中哪一个具体问题，回答后会改变何种认识。区分作者宣称的 novelty 与从已读材料能核验的新意，不凭有限检索宣称“首次”。

“用 CRISPR 敲除 X”是操作；“X 是否为表型 Y 所必需”才是可检验问题。发现敲除效应也不自动证明直接调控或充分性。区分描述、预测、机制与因果问题，它们需要的证据不同。

重建：

```text
Background → Knowledge Gap → Scientific Question → Hypothesis → Research Strategy → Evidence → Interpretation → Conclusion
Question → Hypothesis → Method → Evidence → Interpretation → Conclusion
```

作者没有预设假设的探索性研究，记录实际探索目标；不要事后把每个发现包装成预注册预测。作者选用方法的动机若未交代，只能将合理解释标为分析判断。

## 关键实验如何构成论证

对每个关键实验建立：

```text
Purpose → Design → Prediction → Observation → Interpretation → Role in argument
```

说明系统、样本单位、对照、干预、测量指标、时间顺序和关键混杂。假设为真与竞争假设为真分别预期看到什么？实际观察是否足以区分两者？把这些回答连接到具体 Figure/panel、Methods 和补充结果。

| 层次 | 应写的内容 |
| --- | --- |
| Observation | 仪器、图像或数据实际显示什么，附位置 |
| Evidence | 在对照、误差与统计条件下，这些观察支持哪个判断 |
| Interpretation | 作者提出什么解释，依赖哪些额外假设 |
| Conclusion | 最终回答了哪个问题，在什么系统和范围内成立 |

实验可能是并列验证、递进、排除竞争解释或跨尺度连接。不要强制所有论文符合“现象 → 因果 → 机制”的理想顺序。指出删除某个实验后论证缺哪一步；如补充材料含关键对照，应纳入同一条证据链。

## 模型与证据

区分模型用于解释已有数据、产生新预测、抽象机制三种角色。模型可以兼具多种角色，但拟合曲线不能单独证明真实机制。模型教学细节见 [quantitative-models.md](quantitative-models.md)，测量细节见 [experimental-methods.md](experimental-methods.md)。

## 批判性分析与下一步

把作者明确承认的限制与自己的判断分开。主动检查样本、对照、技术误差、因果识别、模型假设、参数不确定性和泛化。缺方法报告意味着无法评估，不等于已经证实方法有错。

针对核心结论逐条问：相关是否被解释为因果？体外是否外推到体内？特定条件是否外推为普遍规律？观察现象是否被解释为唯一机制？非显著结果是否被当作等效或无作用？记录具体断点与可补充的证据。

Alternative Explanations 应有依据和区分方法，不能泛写“可能还有其他因素”。以“竞争解释 → 为什么目前没被排除 → 区分性实验或分析 → 不同结果分别支持什么”组织。补实验要有针对性，不默认更大样本就能解决设计偏差或不可辨识性。

后续问题采用“问题 → 假设 → 方法 → 可能结果 → 意义”，允许支持与不支持两种结果，不能把预测写成即将得到的事实。将科研训练落在具体选择上：哪个对照排除了什么，哪个方法用较少假设回答了问题，哪个图把推理跳跃暴露出来。

延伸阅读按 Prerequisite → Classic → This Paper → Follow-up → Frontier 组织。每条解释阅读目的并指向核验记录。没有查到后续研究时说明检索范围与日期，不以模型记忆补出所谓最新进展。
